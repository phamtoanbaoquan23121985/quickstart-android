# AEGIS-Ω PHANTOM BOUNDARY

Pure-logic research components for SIF, BCL, CBR and the REALITY GATE.

- **SIF:** canonical structured-observation fingerprints and structural path diffs; never perform arithmetic on digests.
- **BCL:** detects capability growth across a boundary. New capabilities require explicit scoped delegation and a non-empty evidence reference. Legitimate URI grants must be represented as delegation.
- **CBR:** generates one-factor-at-a-time replay cases for identity, authority and payload. Outcome differences are observations, not proof of exploitability.
- **REALITY GATE:** fail-closed outside physical Pixel 10 Pro (blazer) / Pixel 10 Pro XL (mustang), API 36 and authorized scope. Requires repeatability, invariant violation, platform attribution, safe PoC, independent review and OBSERVED evidence.

Run pure-logic tests from repository root:

    python -m unittest discover -s aegis-reality/phantom_boundary/tests -v

These tests are not device tests. REPORTABLE means eligible for human/program triage only; confirmed_vulnerability remains false until the receiving program independently confirms it.
